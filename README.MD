A Snake Game is a simple and popular game that can be created using HTML, CSS, and JavaScript.

🎮 How it works
🐍 The snake moves around the game area.
🍎 The snake eats food.
📈 Every food item increases the score.
🐍 The snake becomes longer after eating.
💥 The game ends if the snake hits the wall or itself.
🔄 A restart button can start the game again.
